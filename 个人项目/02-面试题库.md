**Q42. 队列满了怎么办？有拒绝策略吗？** 🔴

**Q43. 入队失败为什么返 503 而不是 200？** 🟢 **最强的一题，务必讲透**
> "Fluent Bit **只看 HTTP 状态码、不解析响应体**。返 200 会让它误判成功并删掉本地磁盘缓冲 → **静默丢日志**（没有任何报错信号）。所以必须在 Controller 方法内捕获异常返 503，还不能冒泡到返回 HTTP 200 的全局异常处理器。"

**Q44. ES 不可达时怎么降级？降级后用户看到什么？** 🟠
> 检索回退 PG 聚合行，返回 `degraded=true`，前端显式提示"聚合视图"。
> **三态要分清**：无授权 / 降级 / 空结果，不能混。

**Q45. 那 7 类告警规则具体是哪 7 类？** 🟢
> 错误率阈值、消费积压、死信、环比突增、慢接口 p95、**服务静默**、**ES 降级**（**最终版已补全**）。

**Q46. p95 怎么算的？为什么不用平均值？** 🟠
> ES `percentiles` 聚合（TDigest 近似）；平均值会被大量快请求稀释，掩盖长尾。
> **真实坑**：样本门槛用"窗口内总条数"判定，但 `percentiles` 只对**带 durationMs 的文档**生效 → 样本集不同源，p95 拿不到值。**门槛与取值必须用同一样本集。**

**Q47. "指纹收敛"怎么算指纹？为什么不用哈希？** 🔴
> 是**明文** `ruleId + ":" + target`（截断 160），**不是哈希** —— 刻意做成可读可对照。

**Q48. 静默窗口怎么实现的？** 🟠
> **真实坑（很值钱）**：防刷屏原本按 `notifyStatus = SENT` 统计历史事件，但事件收敛后该字段会被后续轮次覆盖（SENT → SUPPRESSED）→ 再也查不到"发过" → **每轮都发邮件**。改成按**通知时间**（单调、不被覆盖）判定。
> **这个坑单轮测不出来，第二轮才复现** —— 讲出来极有说服力。

**Q49. SHA-256 加盐怎么加的？** 🔴
> **实际无盐**。正确答法："用的是 32 字节 `SecureRandom` **高熵密钥**，不是用户密码，所以没加盐（加盐收益低）；密码场景才必须加盐 + 慢哈希。摘要比较用**常量时间比较**防时序攻击。"

**Q50. 四维权限是取并集还是交集？** 🟠
> **同维 OR、跨维 AND；两条通道（四维 scope ∪ key 归属）之间是 OR**。做成交集会让用户什么都看不到。
> **加分（你的真实 bug）**：降级路径的权限过滤器"签名收参数但方法体没赋值"，导致只配环境维度的用户**降级时拿到全表** → 修复为 fail-closed。**教训：写了 ≠ 接上了。**

**Q51. 管理员为什么也受"无授权不可见"约束？** 🟢
> **管理权与数据权正交** —— 管理员是"日志中心的运维者"，不等于能看业务日志。

**Q52. `search_after` 的原理？为什么不能用 `_id` 做 tiebreaker？** 🟢
> 拿上一页末条排序值做游标；ES **不允许对 `_id` 排序**（直接 400），要用文档自身的 `id`。

**Q53. SSE 建连后为什么"立即输出响应头"？** 🟢 **你最值钱的一个数字**
> Spring 的 `SseEmitter` 在第一次 write 前不送响应头，而浏览器 `onopen` 要等响应头 → 表现为"已连接"要等 5-6 秒。
> 修法：建连后立即发一个**注释帧**。**实测首字节 2.18s → 0.009s。**
> **一定要说出这个数字** —— 它证明你会定位非功能性问题和量化结果。

**Q54. 多实例部署时 SSE 怎么保证每个用户都能收到？** 🔴
> **未实现**：emitter 容器和事件分发都在进程内，**当前只支持单实例**。
> 正确答法：承认 + 说方案（Redis pub/sub 或 MQ 转发）。**主动交代比被问出来强。**
